### Added

- Typing `/` and choosing a platform of the store (YouTube, for example) now adds a platform chip: your clear request that the agent may use the paid tools of that platform as it sees fit. The agent searches that platform, lists the matching tools with prices, gives the expected total and asks once.

### Changed

- The store is paid, so the agent now uses it only when a store chip (a tool or a platform) is in the conversation. With only the name in words, it tells you to type `/` and the name. A tool chip counts as your request, so the agent no longer asks again whether to use it; the cost approval is the same. When the store is not available, the agent says why instead of using the browser.
