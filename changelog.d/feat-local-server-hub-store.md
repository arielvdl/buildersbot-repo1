### Added

- The Store (paid tools through Cultura Builder) now works for the agents of a server that Builders Bot
  runs on your computer, and the message box offers the Store picker there. Before, only the first server
  had it. The server asks Builders Bot to run each Store call, so your Cultura Builder sign-in stays in
  Builders Bot and is never given to the server. Joined servers of other hosts do not get the Store.
