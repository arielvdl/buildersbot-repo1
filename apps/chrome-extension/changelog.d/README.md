# Unreleased extension notes

The notes of the Builders Bot extension for Chrome. The extension has its own version
(`apps/chrome-extension/package.json`) and ships through the Chrome Web Store, apart from the app, so
its notes are separate from [`changelog.d/`](../../../changelog.d/README.md). Name each file after the
branch, with `-` for `/`, and use the groups and item rules of
[the release notes](../../../docs/RELEASING.md#release-notes).
