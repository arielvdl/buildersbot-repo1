### Changed

- When a server cannot update itself, the update notice asks the host administrator for a compatible
  Builders Bot release. Before, it named the release page of the Builders Bot project.
- The app does not check for over-the-air updates and does not offer a store version in this
  version. Before, it read the over-the-air updates of the Builders Bot project, and the update notice
  opened the store page of the Builders Bot app.
