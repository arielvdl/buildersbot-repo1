# Dossiê de Titularidade — Builders Bot

Este diretório reúne o **dossiê de titularidade** do Builders Bot: o conjunto de
documentos que comprova que a CULTURA BUILDER EDUCACAO E TECNOLOGIA LTDA detém os
direitos patrimoniais sobre o produto, seu código-fonte e seus ativos derivados,
inclusive em relação ao histórico de desenvolvimento anterior ao repositório atual.

## O que fica neste diretório

| Arquivo | Conteúdo |
| --- | --- |
| `dossie.md` | Registro da exportação: commit de origem, data, escopo de arquivos e pendências contratuais em acompanhamento |
| `contrato.pdf` *(a anexar)* | Instrumento contratual que instrumentaliza a aquisição/cessão dos direitos sobre o produto |
| `anexo-shas.md` | Anexo técnico com os SHAs dos commits de origem, o commit-base e o hash da lista |
| `assinaturas/` *(a anexar)* | Cópia assinada do contrato e do CLA retroativo, quando concluídos |

Os itens marcados como "a anexar" devem ser adicionados à medida que forem
formalizados; nenhum documento do dossiê deve afirmar fato ainda não respaldado
por peça assinada.
